How It Works

Home score = Routine done today + Habits done today + Goals progress, averaged. Haven't added something yet? It's skipped, not counted as 0. Keeps it fair.

Not everything should count toward your score. 'Lunch at 1pm' isn't progress, but 'Study' is. Turn off 'Count in progress' for the boring stuff.

Goals come in 3 types. Lifetime total keeps adding up forever (like 210 pages total) — today's score is 100% only if you actually added something today, 0% if you didn't touch it. Daily check-off is for stuff you do once a day for N days (like waking up early for 30 days) — one tap marks today done, just like a habit. Daily quota resets every midnight (like 8 glasses of water) — today's number out of target is today's score, fresh start tomorrow.

Streak = days in a row you did a habit. Miss a day, it drops to 0. Start again next time you check it off.

Everything stays on your device only. Nobody else can see it. Want a copy or moving phones? Use Export below.
